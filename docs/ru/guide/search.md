# Поиск и фильтры

Поиск и фасеты сужают один набор вместе: сущность совпадает, если прошла текстовый запрос **и** фасет типов **и** фасет
состояний **и** каждую группу потребителя **и** пользовательский предикат.

## Три режима поиска, режим выбирает сам запрос

| Запрос | Режим |
| --- | --- |
| `10.38.24.0/24` | CIDR — адреса внутри подписей сравниваются с диапазоном |
| `10.38.24.*`, `10.38.*.*`, `10.38.24.7*` | Маска — сравнение по строковому виду, поэтому `.7*` найдёт и `.7`, и `.70` |
| `beelink` | Регистронезависимая подстрока |

База CIDR может быть любым адресом внутри сети: `10.38.24.5/24` — тот же диапазон, что и `10.38.24.0/24`.

Какие поля искать — решаете вы:

```ts
const filterOptions = {
  searchFields: (entity) => [entity.label, entity.meta?.fqdn ?? '', ...(entity.sublabels ?? [])],
}
```

По умолчанию — название плюс все подписи.

## Совпадения и то, что остаётся вокруг них

`applyFilters` возвращает два множества:

- `matchedIds` — прямые совпадения, их подсвечивает рендер;
- `visibleIds` — всё, что остаётся на карте: совпадения плюс соседи на `neighborDepth` шагов плюс цепочки предков,
  если не выключен `keepPathToRoot`.

Соседи и путь до корня — это то, что не даёт поиску рассыпать граф на отдельные кружки. Узел вне области видимости не
просто не показывается — он ещё и не служит мостиком на следующий шаг.

```ts
const filterOptions = {
  neighborDepth: 2,
  keepPathToRoot: true,
  layers: ['physical'],
}
```

Пока не активен ни один критерий, `matchedIds` пуст, а виден весь граф: подсвечивать пока нечего.

## Группы фильтров — это данные

Пакет не знает, что такое «подсеть» или «критичность». Объявите группы и то, как читать их с сущности:

```ts
import type { FilterGroupDef } from 'vue-asset-map'

const filterGroups: FilterGroupDef[] = [
  {
    id: 'subnet',
    label: 'Подсеть',
    valuesOf: (entity) => (entity.meta?.subnet ? [entity.meta.subnet] : []),
    options: [
      { value: 'internet', label: 'Интернет' },
      { value: 'vpn', label: 'VPN' },
      { value: 'docker', label: 'Docker bridge' },
    ],
  },
  {
    id: 'severity',
    label: 'Критичность',
    valuesOf: (entity) => (entity.meta?.severity ? [entity.meta.severity] : []),
    options: [
      { value: 'critical', label: 'Критический' },
      { value: 'high', label: 'Высокий' },
      { value: 'medium', label: 'Средний' },
      { value: 'low', label: 'Низкий' },
    ],
    defaultOpen: false,
  },
]
```

```vue
<AssetMap :entities="entities" :links="links" :filter-options="{ groups: filterGroups }" />
```

`options` фиксирует порядок и подписи — здесь критичность идёт по убыванию, а не по алфавиту. Без него значения
собираются из самих данных.

Значения внутри одной группы соединяются по ИЛИ (выбрать «критический» и «высокий» — показать оба), группы между
собой — по И.

## Счётчики не обнуляются при выборе

Фасеты считаются по текущей **проекции**, а не по результату фильтра. Иначе выбор `offline` обнулил бы все остальные
счётчики, и вернуться было бы некуда.

Значения, объявленные в `options` явно, показываются даже с нулём, поэтому список не прыгает, пока по нему кликают.

## Управление состоянием

```vue
<AssetMap
  v-model:filters="filters"
  v-model:open-filter-groups="openFilterGroups"
  :entities="entities"
  :links="links"
  :filter-options="{ groups: filterGroups }"
/>
```

```ts
import { emptyFilterState } from 'vue-asset-map'

const filters = ref(emptyFilterState())
const openFilterGroups = ref<string[]>(['subnet'])
```

Какие группы раскрыты — это состояние компонента, а не `localStorage`: пакет не пишет в хранилище браузера. Сохранять
его между сессиями решает приложение, и `v-model:open-filter-groups` — то, как оно выходит наружу.

## Debounce

Текстовый запрос откладывается на `searchDebounce` (200 мс по умолчанию); клик по фасету применяется сразу, потому что
клик — осознанное единичное действие, и задерживать его значит делать интерфейс вялым. Очистка поля тоже применяется
сразу.

Раскладка сознательно не зависит от фильтра: поиск скрывает и подсвечивает узлы, но не перестраивает карту, иначе граф
прыгал бы на каждой набранной букве.
